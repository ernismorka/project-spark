# Demo limitations / Demonstracijos ribojimai

- Desktop keyboard/mouse and WebGL 2 with hardware acceleration are required. Responsive menus do not imply touch/mobile gameplay. No installer, bundled browser or bundled Node runtime; Node.js 24+ is the only player runtime prerequisite. Unsigned Windows command launcher; no automatic tool downloads or administrator access.
- Single existing episode, session-local progress. Replay/end/reload reset all progress. No persistence, accounts, telemetry, online hosting or public release. Shut down the console with Ctrl+C and close game tabs after play.
- The optional cooperative pilot requires its separately started loopback server and two local browser clients. It is not integrated into the 3D episode; the packaged launcher serves only single-player/practice. No remote multiplayer, chat or matchmaking.
- Measurements use the deterministic ideal steady-state resistor/voltage-source solver. Decorative capacitors, LEDs and MCU are not electrically simulated. The commissioning network is separate from diagnosis; OUT/service display is abstract status. Programs use the bounded closed interpreter, never arbitrary player JavaScript.
- Current Chromium and Firefox are tested in Linux CI with software graphics; Windows Firefox automation has an existing spawn UNKNOWN restriction. That launch failure is not a passed local browser check. Graphics initialization can fail on exhausted/unsupported drivers; explicit retry and browser guidance remain.
- Sustained target-hardware FPS, long-session memory behavior, target-age engagement, learning transfer, native-speaker copy review, assistive-technology usability and two-human cooperative enjoyment remain consolidated playtest work. Short automated frame/memory observations are not certification.

Reikia klaviatūros, pelės, WebGL 2 ir Node.js 24+. Pažanga neišsaugoma: pakartojimas, sesijos pabaiga ar puslapio perkrovimas pradeda iš naujo.
